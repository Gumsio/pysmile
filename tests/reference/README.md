# R reference fixtures

These small TSV files are **test fixtures only**, generated by executing
the original R implementation on the synthetic `predictions.tsv` input.
They are never loaded by production code. Normal Python tests require no R
installation, network access, or fixture regeneration.

Source: [bbwieckowska/Usmile, commit ac0fe64bb42dc81f3112d698279e39b3a6274561](https://github.com/bbwieckowska/Usmile/tree/ac0fe64bb42dc81f3112d698279e39b3a6274561/R).
Retrieved and executed on 2026-10-24. R/ggplot2/pROC versions are recorded
in `versions.txt`. Original source behavior is attributed to the Usmile
authors under the upstream MIT license; no upstream source is vendored here.

Verify file identities with `git hash-object path/to/file.R`. With ggplot2
and pROC installed in a development R environment, regenerate using:

```sh
Rscript tests/reference/generate.R /path/to/pinned/R tests/reference
```

The generator explicitly sources both PIW definitions in sequence and captures
them separately. The file named `3_function_PRCplot.R` defines another
`PIWplot`; it does not provide a resolved precision-recall implementation.

Fixture roles:

- `predictions.tsv`: input with all four subclasses, exact ties, and tiny
  nonzero changes exposing the duplicate PIW definitions.
- `us_*_values.tsv`, `us_*_summary.tsv`: independently computed R coefficient
  results for rLR, BA, RB. R always supplies a finite overall likelihood-test
  p-value for this input; Python BA/RB intentionally retain their existing NaNs.
- `us_*_points.tsv`: point geometry, colors, fills, sizes, and R shape 21
  obtained from `ggplot2::ggplot_build(USplot(...))`.
- `piw_exact_points.tsv`, `piw_tolerance_points.tsv`: R-built point layers
  from the duplicate and primary PIW definitions respectively.
- `roc_curves.tsv`, `roc_results.tsv`: pROC-derived curve data and formatted
  summaries returned by the actual R `ROCplot` call.
- `calibration_curves.tsv`, `calibration_results.tsv`: occupied-bin summaries
  and Brier summaries returned by the actual R `CLBplot` call with five bins.
- `roc_lines.tsv`, `calibration_lines.tsv`: R-built line geometry and styles,
  retaining group order, vertical segments, and calibration marker codes.

The tests compare numerical geometry/styles rather than raster screenshots
so they are independent of local font rendering. Synthetic inputs and these
statistics are confined to tests, and do not provide production statistics.
